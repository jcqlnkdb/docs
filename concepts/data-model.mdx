TaskFlow manages two resources: **projects** and **tasks**. A task always belongs to exactly one project, and a project can contain zero or more tasks. A task cannot exist outside of a project.

## Projects

A project is a container for related tasks.

| Field | Type | Description |
|-------|------|-------------|
| `project_id` | string (UUID) | Unique identifier generated by the API when the project is created. Required to create tasks. |
| `name` | string | Project name. Required when creating a project. |
| `description` | string \| null | Optional project description. Returns `null` when not provided. |
| `created_at` | string (ISO 8601, UTC) | Timestamp when the project was created. |

Example response:

```json
{
  "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "API Documentation Revamp",
  "description": "Rewriting all public-facing API docs for v2.",
  "created_at": "2026-05-17T10:30:00.000Z"
}
```

## Tasks

A task is a work unit inside a project.

| Field | Type | Description |
|-------|------|-------------|
| `task_id` | string (UUID) | Unique identifier generated by the API when the task is created. |
| `project_id` | string (UUID) | ID of the project this task belongs to. Required when creating a task. |
| `title` | string | Task title. Required when creating a task. |
| `description` | string \| null | Optional task description. Returns `null` when not provided. |
| `status` | string | Current state of the task: `pending`, `in_progress`, or `done`. |
| `created_at` | string (ISO 8601, UTC) | Timestamp when the task was created. |
| `updated_at` | string (ISO 8601, UTC) | Timestamp of the last update. Equal to `created_at` at creation. |

Example response:

```json
{
  "task_id": "f9e8d7c6-b5a4-3210-fedc-ba9876543210",
  "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "title": "Write introduction page",
  "description": "Draft the overview and getting started sections.",
  "status": "pending",
  "created_at": "2026-05-17T10:35:00.000Z",
  "updated_at": "2026-05-17T10:35:00.000Z"
}
```

See [Task lifecycle](/concepts/task-lifecycle) for how the `status` field changes over time.

## Identifier behavior

<Warning>

Both `project_id` and `task_id` are UUIDs generated by the API at creation. They are immutable and unique. TaskFlow does not provide endpoints to retrieve them later — store them in your own system as soon as you receive them.

</Warning>
